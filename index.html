위클리 주차(W32 등)는 보고 주차, 기준일은 해당 위클리의 대표일입니다. 제목의 날짜는 각 품목 실제 평가일로 별도 저장됩니다.
예: W32 / 기준일 2026-08-07
AN 브리핑 제목이 2026-08-04여도 W32·2026-08-07 그룹에 저장되고, AN의 실제 평가일은 2026-08-04로 보존됩니다.

전체 위클리 파싱 · 자동저장
여러 품목 브리핑을 한 번에 붙여넣습니다. 품목 순서는 무작위여도 제목을 기준으로 자동 분류합니다.
입력된 품목만 해당 W주차에 추가·업데이트하며, 입력하지 않은 기존 품목은 삭제하지 않습니다. 개별 제목의 날짜는 실제 평가일로 보존됩니다.
예: W33 / 기준일 2026-08-14
AN 8/11, PC 8/12, US BD 8/7처럼 평가일이 달라도 모두 W33 그룹에 저장할 수 있습니다.
전체 파싱 규칙
각 품목은 제목 : 품목명 종목 브리핑 (YYYY-MM-DD)로 시작하면 됩니다. WTI·SM·BD·AN·BPA·MMA·Benzene·Ethylene·Propylene·ABS·PC·EPS·PS·PBR·Europe/US SM·Europe/US BD를 순서와 무관하게 인식합니다. ai 전망이 있으면 함께 보존·표시합니다.
전체 위클리 텍스트를 붙여넣으면 인식 품목 수와 품목명이 자동 표시됩니다.


전체시장 Overview 파싱 · 자동저장
현재 W주차의 전체시장 Overview만 weekly_meta에 저장합니다.
코멘터리 / 상승요인 / 하락요인 / 전망 4개 섹션과 각 섹션의 요약: 한 줄을 그대로 붙여넣으세요.
예: W32 / 기준일 2026-08-07
Overview는 개별 품목 평가일과 무관하게 위클리 기준일과 W주차 기준으로 저장됩니다.
입력 형식
코멘터리 → 본문 → 요약: ... → 상승요인 → 본문 → 요약: ... → 하락요인 → 본문 → 요약: ... → 전망 → 본문 → 요약: ...
해당 W주차 Overview만 자동저장합니다. 품목 데이터는 변경하지 않습니다.
